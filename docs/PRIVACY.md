# 隐私与数据

## 本机保存的数据

应用数据目录为 `%LOCALAPPDATA%\Yike\`。程序兼容早期 WindowsTranslator 数据目录，会在目标文件不存在时迁移旧数据。

- API 密钥：通过 Windows DPAPI 的 CurrentUser 范围加密保存为 key.bin。
- Yike 登录会话：通过 Windows DPAPI 的 CurrentUser 范围加密保存为 remote-session.bin；邮箱和额度信息与令牌一起加密。密码和邮件验证码不保存。
- 账号昵称与头像：按邮箱区分，通过 Windows DPAPI 的 CurrentUser 范围加密保存为 remote-profiles.bin；只在本机显示，不上传服务器。
- 偏好、代理与历史：保存在本机；历史默认启用，可在设置中关闭或清理。
- 图片历史和语音处理文件：可能包含用户输入、截图或录音结果，不应作为开发资料上传。
- 旧账号数据：兼容已有本机数据，但不会作为服务器登录凭据。

DPAPI 只保护密钥等加密数据，不代表历史文字、图片和缓存全部加密。同一 Windows 用户权限下的软件仍可能访问应用数据。

## 网络连接

| 功能 | 处理位置 / 接收方 |
| --- | --- |
| Yike 注册、登录与额度查询 | `https://n5v1b.cn/yike-api/`；注册时发送邮箱、密码和邮件验证码，登录时发送邮箱与密码 |
| 公共额度文本翻译、OCR 结果翻译 | Yike 服务接收登录令牌与待翻译文字，再调用 DeepL；服务端不长期保存原文，译文仅为请求去重短时缓存 |
| 个人密钥文本翻译、OCR 结果翻译 | DeepL API，使用用户配置的密钥 |
| 短词常用释义 | “了解与帮助”中的“联网补充常用释义”默认开启，沿用已有多义释义行为。中英互译的单词或短词组会发送到有道词典 `https://dict.youdao.com/jsonapi`；不发送账号、密钥、历史或长句。关闭后不再请求，并取消进行中的词典查询、清空内存缓存。词典不可用时保留原译文 |
| 图片 OCR | Windows 本机 OCR |
| 离线语音识别 | 本机 Whisper 运行库及模型 |
| 在线自然语音 | Microsoft 在线语音服务，发送朗读文本 |
| 本机朗读 | Windows 已安装的语音 |
| 在线更新检查 | 点击检查更新时请求 GitHub Releases API；选择下载并安装时从对应 GitHub Release 下载公开安装包，并校验大小和 SHA-256。不发送翻译内容、密钥或历史。自定义 update-source.txt 仍只支持 HTTPS |

用户配置代理后部分网络请求会经过该代理。在线自然语音脚本在代理连接失败时会尝试直连。

词典补充最多显示 4 个释义；内存缓存最多 128 条、每条 10 分钟失效，退出后不保留，不写入磁盘。词典单次等待上限为 2.5 秒（包含读取响应），响应上限为 1 MiB。取消翻译或较早请求返回时，不会用过期词典结果覆盖新任务；词典失败不会自动切换翻译引擎或额度来源。

## 公开仓库

源码不需要个人 .env、DeepL 密钥或云服务器配置。请在应用界面中配置密钥，不要直接写进源码或工作流。

.gitignore 排除运行库、安装包、模型、临时输出、密钥与常见本机数据。它不会自动清除已提交到 Git 历史的文件；提交前请检查实际暂存内容。问题报告和日志也需要脱敏。
