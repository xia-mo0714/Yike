# 代码结构

Yike 使用 C# 与 WPF，命名空间保留为 WindowsTranslator，产品名称为 Yike。构建脚本将 src 和 tests 下的 C# 文件一起编译，并复制窗口 XAML 和辅助脚本。

| 目录 | 职责 |
| --- | --- |
| Application | 启动、托盘、单实例与共享状态 |
| Features | 翻译、设置、OCR、图片、划词、语音与历史 |
| Presentation | 主窗口绑定、主题、公共控件、XAML 与独立窗口 |
| Infrastructure | DeepL、加密存储、图像、OCR、语音、更新与 Windows API |
| Domain | 偏好、历史、OCR 与图片模型 |
| Diagnostics / tests | 自测、界面检查与离线预览 |

App 通过 partial class 按功能拆分，各文件共同组成同一个应用类。部分成员来自历史版本源码恢复，保留其字段与方法以维持现有行为；尚未全面调整命名和依赖关系。

设置界面包含“账号与安全”页面。Infrastructure/Accounts 提供邮箱验证码注册、登录、DPAPI 加密会话、额度刷新和公共翻译客户端；旧本机账号数据仅用于兼容历史身份数据，不会作为服务器登录凭据。

外部进程由 OCR、语音适配层管理。语音运行库通过应用目录下的 speech-runtime 和 whisper-runtime 加载，不依赖构建者的用户路径或旧安装包。
