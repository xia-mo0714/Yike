- 原生与 CLI 共用最多两次最终解码和一个截止时间。低可信结果保留文字并提示核对；未知概率不冒充低可信。

- 独立审查的四项重要发现已复现并修复：排除应用目录中未验证的传递 DLL；旧取消不清除新会话；开始回执之后的提前停止不被丢弃；中断、时长上限及空结果恢复界面且保留低可信核对提醒。完整回归与十六张预览复验通过。

## 验收原则

完整功能自测并不等于真实准确率达标。运行 `tools/test-phase2-speech.ps1 -Mode Full`，逐项报告 Pass / Fail / Unverified；不能挑选最快结果、删除失败记录、重写参考或更改评分规则。

冻结第一阶段十五项音频、参考、模型和评分器。当前实测平均 CER 仍为 **9.21%**；低音量/风扇噪声合并中位 CER 仍为 **15.38%**，没有严格改善。低可信重试开启后也没有改善，因此新后端与低可信重试均保持关闭。

实际采集就绪：第一阶段十次冷启动中位 **548.23 ms**；第二阶段十次暖启动中位 **113.11 ms**，冷启动第一次 **884.25 ms**。最终识别中位 **2366 ms**，第一阶段 **2098 ms**，超过允许的 10% 增幅。暖启动更快不意味着最终识别更快或更准确。

三十次实际开始/停止/取消通过；释放后所属辅助进程与录音目录均为零，主进程私有内存增量 **9,789,440 字节**。新版三十分钟间歇稳定性复测通过：1864105 ms、30 轮、373 个采样；释放后私有内存增量 12992512 字节（约 12.39 MiB），所属辅助进程和录音目录均为零，空闲 CPU 中位 0.0130%。完整证据保存在交付目录 evidence-final/。

首个草稿的物理参考播放、真实麦克风拔插/切换、用户问题视频的独立可靠听音参考均 **Unverified**。注入设备测试不能替代实际硬件证据。没有可靠参考时不产生或保存私人视频转写，不宣传准确率问题已经解决。

## 安装与交付

候选输出 `release/phase2-speech/`。隔离安装仅使用限定的 `--verify-install` 和全新系统临时目录，复用本地校验模型，不触碰普通安装协议。`tools/test-phase2-install.ps1` 校验安装、自测、卸载及真实 LOCALAPPDATA、Roaming、已安装程序、注册项和快捷方式哈希不变。

`tools/test-phase2-installer-guards.ps1` 检查缺工作程序/ABI/全部依赖/许可、坏元数据/原生 DLL、坏嵌入 ZIP、非拥有目录和锁文件保留。所有正式启用与本机覆盖都要求完整验收及独立审查无阻塞；失败或未验证时仅交付候选，不覆盖现有版本。

具体最终包大小、SHA-256、版本、隔离测试及全部门槛见本机交付目录的 `verification.json` 和 `handoff.md`。第一阶段安装包及用户备份必须保留，私有数据不进入 Git 或安装包。
